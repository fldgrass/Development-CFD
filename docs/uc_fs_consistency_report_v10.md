## 1. 발견·수정한 근본 결함 — 단위셀 압력 BC 부적정(ill-posed)

`openfoam/unit_cell/0/p`가 **입구(zMin) p=fixedValue 0 + 출구(zMax) p=zeroGradient**로
되어 있었다(전체구조 템플릿과 정반대). 입구에서 U·p 동시 Dirichlet(과잉지정), 출구는
U·p 모두 Neumann(과소지정) → 그물 항력으로 하류압이 떨어질수록 압력방정식이 p고정
입구에서 유량을 보정하는 **양성 되먹임 = 질량유량 폭주**.

증거 (`postProcess flowRatePatch`, 공칭 1.6e-3 m³/s):

| 시점 | 입구 유량 | 유입속도 | Cd(그 시점) |
|---|---|---|---|
| t=500 (구 BC) | 2.21e-3 | 1.38 m/s (+38%) | 1.25 (드리프트 중) |
| t=2000 (구 BC) | 4.33e-3 | 2.71 m/s (+171%) | 4.35 (발산성 상승) |
| **수정 후 t=297** | **1.60000e-3** | **1.000 m/s (오차 0)** | **0.6806±0.0001 (정식 수렴)** |

수정: 입구 p=zeroGradient, 출구 p=fixedValue 0, 출구 U=inletOutlet (FS 템플릿과 동일 표준).
**영향: 2026-07-02 이전의 모든 UC 절대 Cd는 드리프트 스냅샷으로 무효.** v8의 "A90에서
UC 1.108 vs FS 1.061 = 4.2% 일치"는 드리프트가 우연히 1.1을 지나던 순간의 허구적 일치였다.

## 4. 결론 — Cd 차이는 물리적 (유한 vs 무한)

수치 원인(수렴·질량·도메인·격자·후처리·좌표계)을 전부 정리한 뒤에도 남는 35%는
**서로 다른 물리계**의 정당한 차이다:

- **UC = 측방 무한 스크린**: 유량이 강제 통과(우회 불가), 후류 결손 0. 압력강하
  (K=0.567, Sn≈0.20 스크린 손실계수 문헌 범위)의 상당분이 개구부 **제트의 초과
  운동량**으로 하류에 수송되어, 그물선에 걸리는 순힘은 Δp·A보다 훨씬 작다
  (검증: Δp·A=0.465N, 제트 운동량 플럭스 보정 ≈0.36N → 그물선 힘 0.105N ✓).
- **FS = 유한 3×3 그물**: 유동이 감속(통과속도 ≈0.88U0)·우회하며 전역 후류를 형성.
  그물선은 준자유류 원기둥(Re≈2500, Cd≈1.0–1.2)처럼 거동 → Cd 1.055,
  하중은 그물 전체에 균일.
- 배열 크기 N→∞에서 FS 내부는 UC로 수렴(점근적 동등). **3×3은 유한크기 효과가
  지배하는 영역**이므로 절대값 일치를 요구할 수 없다.

## 5. 실무 지침

1. 소형 조립체(≤수 셀)의 실제 항력 → **전체구조 모드**.
2. 대형 가두리 그물(수백 셀) 내부·질량-스프링 모델 입력 계수 → **단위셀 모드**
   (이제 수치적으로 신뢰 가능).
3. **과거 UC 결과(CSV·케이스)는 재해석 필요** — BC 수정 후 값만 사용.
4. 진단 습관: `postProcess -funcs '(flowRatePatch(name=zMin))'` 로 유량=U0×A 확인.

`results/full_structure/v10fine_A90`(FS 정밀), scratchpad `compare_uc_fs.py`·`uc_fs_compare.json`.
