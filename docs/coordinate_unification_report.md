# 좌표계 통일 — 변경 전/후 비교 리포트

작성 2026-06-29 · 대상: Unit Cell ↔ Full Structure 좌표계 통일 (저위험 프레임 표시 통일)

## 1. 통일 표시 좌표계 (목표 규약)

- 전역 축: **+X = 그물면 법선(정면)**, **X–Y = 수면**, **+Z = 수심(↓)**
- 그물 형상은 **Y–Z 평면**에 놓임(법선 +X)
- 유속 단위벡터 **d(AoA) = (sin AoA, −cos AoA, 0)**
  - **AoA = 90° → 유속 −X→+X (그물 정면 충돌, 법선 입사)**
  - **AoA = 0° → 유속 +Y→−Y (그물면 평행, 그레이징)**
- dragDir = 유속 방향, liftDir = 유속 수직(수면 내) = (cosα, sinα, 0), pitchAxis = +Z(수심)

## 2. 변경 전/후 좌표 정의 비교

| 항목 | 전: Unit Cell(솔버) | 전: Full Structure(솔버) | 후: 통일 표시(양 모드 공통) |
|---|---|---|---|
| 그물면 법선 | +Z | (sinα, 0, cosα) | **+X (그물 Y–Z 평면)** |
| 유속 방향 | (cosα, 0, sinα) | +X 고정(그물 Y축 α회전) | **(sinα, −cosα, 0)** |
| AoA=0 유속 | +X | +X | **−Y (그레이징)** |
| AoA=90 유속 | +Z | +X | **+X (정면)** |
| dragDir | (cosθ,0,sinθ) | +X | **유속 d(AoA)** |
| liftDir | (−sinθ,0,cosθ) | +Z | **(cosα, sinα, 0)** |
| 수심 축 | (암묵) | (암묵) | **+Z** |

**구현 방식(사용자 선택: 저위험):** 검증된 솔버 내부 좌표는 그대로 두고, 화면·리포트·
시각화만 통일 표시 프레임으로 변환한다. 변환은 모드별 회전행렬 `solver_to_display_rotation`:

- `R_uc = [[0,0,1],[−1,0,0],[0,−1,0]]` (각도 무관)
- `R_fs(α) = [[sinα,0,cosα],[−cosα,0,sinα],[0,−1,0]]` (각도 의존)
- 두 R 모두 det=+1(정상회전). 시각화에서 메시·벡터장·STL을 R로 회전(`_apply_display_frame`).

## 3. 좌표 변환 일관성 검증 (해석적)

`verify_coordinate_consistency()` — 0/30/45/60/90° 전부 통과(상대각 차이 0.000°).
각 모드의 솔버 유속·법선이 R 적용 후 통일 표시 프레임 d(AoA)·법선(+X)으로 정확히 변환됨.

## 4. 다중 AoA CFD 검증 (실측, U=1.0 m/s)

`display_flow`(솔버유속을 R로 변환) = `target d(AoA)` 가 **모든 케이스에서 일치(8/8)**.

### 물리 타당성
- **Cd 단조 증가**: 그레이징(0°)→정면(90°)으로 두 모드 모두 증가. ✓
- **Cl 거동**: 대칭 극단(0°·90°)에서 ~0, 중간각(45–60°)에서 최대. ✓ (사각에서만 양력 발생)
- **정면(90°) 모드 일치**: UC 1.013 vs FS 1.061 = 4.5% (유한 vs 무한 가장자리 효과, 물리적).
- **drag/lift 방향 일관**: 통일 프레임에서 drag는 항상 유속 d(AoA)과 정렬, Cd>0(항력은 유속 저항).

## 5. Cd/Cl 불변성 (변경 전/후)

본 작업은 **솔버 셋업을 변경하지 않았다**(출력단 프레임 변환만). 따라서 동일 케이스의
**Cd/Cl 스칼라 값은 좌표 통일 전/후 동일**하다(프레임 불변량). 위 표의 값이 곧 전·후 공통 값이다.
바뀐 것은 **표시 좌표(유속·그물 배치·항력/양력 방향)의 통일**이며, 물리 결과는 보존된다.

## 6. 시각화 검증
- `CFDVisualizer`가 케이스 경로/이름에서 모드·영각 자동 감지 → R 적용.
- 실측: unit_cell A45 평균 유속 → (0.74,−0.67,0)≈d(45), full_structure A90 → (1,0,0)=d(90).
- 슬라이스·입체 렌더 무오류, 그물이 Y–Z 평면(법선 +X)으로 표시, STL 투명도 전 모드 적용.

## 결론
두 모드가 동일한 통일 표시 좌표계(그물 Y–Z, 유속 d(AoA))로 일관되게 표시되며, 좌표 변환은
모든 대표 영각에서 정확하고(8/8), 물리 결과(Cd/Cl)는 보존된다. 항력/양력 방향도 통일 프레임에서
일관된다.
