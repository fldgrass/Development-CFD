## 판단

- 비정상성 포착에는 성공했고, Cd 를 6% 끌어올렸다.
- 그러나 문헌값과의 −31% 는 그대로 남는다. 부족분의 주원인은 후류 비정상성이 아니다.
- Cd 변동/평균이 0.4~0.8% 로 작은 것은 물리적으로 타당하다. 그물은 다수의 가는
  실에 힘이 분산돼 개별 실의 방출 위상이 상쇄되므로, Cl 은 뚜렷이 진동해도 합력
  항력의 변동은 작게 나타난다. 따라서 '변동/평균 ≥ 5%' 라는 종전 판정 기준은
  그물 형상에는 부적합하며, Cl 주파수(St)로 판정해야 한다.
- 시간평균이 후반에도 반주기당 +0.3% 정도 미세하게 오르고 있어 완전 포화는 아니다.
  0.2 s 로 연장하면 1.00 안팎에서 안정될 것으로 보이나, −31% 를 설명하지 못하므로
  연장의 실익은 낮다.
